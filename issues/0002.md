## What to build

Detect guesses that are one edit away from the correct word, using case-insensitive edit distance while ignoring punctuation and spacing differences. When that happens, do not broadcast the near-miss guess to the room; instead, send a private chat-style message to that player telling them they were close, while leaving normal incorrect guesses unchanged.

## Acceptance criteria

- [ ] A guess that is edit distance 1 from the answer is treated as a near miss using case-insensitive comparison with spaces and punctuation ignored.
- [ ] The near-miss guess is not shown to other players in room chat.
- [ ] Only the player who made the near-miss guess sees a private “you were close” message in the chat flow.

None - can start immediately
