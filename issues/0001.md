## What to build

Add a user-facing master volume control that applies to all game audio, including background music and sound effects. Lower the default volume from the current behavior and persist the chosen setting locally so the same device uses it on later visits.

## Acceptance criteria

- [ ] A player can change a single master volume control that affects music, countdown audio, and other sound effects consistently.
- [ ] The default volume is noticeably lower than the current default when the game first loads.
- [ ] The selected volume is stored per device and restored on refresh or a later visit from the same browser.
